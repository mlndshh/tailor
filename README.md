# Tailor

Tailor shows every website visitor the version of your site that fits them, and updates its read on every click.
A React SDK plus a decision API. [Jev](https://docs.typesafe.ai) judges who each visitor is from where they came from
and what they do, and code reorders, re-renders and highlights content (never hides it) when Jev is confident.

Built at JEVATHON (2026-09-26). Working name.
